How to pick a hero — the 30-second rule

If it's a PLP: H1 (centered light) — unless it's Vintage / Open Box / Demo Deals, then H3 (dark editorial band). H2 (split product) only on the homepage and high-priority drops.

If it's a secondary content page: H4 (centered light) is the default. H5 (50/50 with image) when you have real photography. H6 (HOF dark) only for HOF + gear heritage articles. H7 (photo overlay) only for drop launches.

If it's a service / program page: H8 (service hero with photo right). Always pair with strip V7 or V10 underneath.

If it's utility: H9. Never on a marketing page.
