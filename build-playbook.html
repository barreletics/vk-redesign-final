Roadmap · Single deliverable

The VK build playbook.

Every locked rule, every template, every header, every PLP layout, every value strip — in the order you'd touch them on a real page. Read this once. Build everything from it. No buffet hunting.

Audience: any team member, designer, or incoming agency developer. Scope: all secondary pages and the PLP / PDP system. Out of scope: homepage / cart / checkout — those live in the locked main prototype (see Reference).

01 / 11

The 6 locked rules.

These never change. If a design proposal breaks any of these, it gets rejected before it gets reviewed. Memorize them.

RULE 01

Minimum font size 12px — everywhere.

No 8/9/10/11px text anywhere in CSS or inline. Eyebrows, badges, footnotes, captions all sit at 12px minimum. Pricing and numbers always render in DM Sans 500.

RULE 02

Slogan is "Vintage Pro Audio."

"Pro Audio Outfitter" is retired. Do not bring it back to any header, footer, or marketing copy. The single tagline visible to users is Vintage Pro Audio.

RULE 03

Amber on secondary, red on core.

--amber #D4860A is the accent for every secondary page (eyebrows, CTAs, accent lines). --vk-red #C0392B is reserved for core ecommerce screens (homepage, category, product, cart, checkout, FAQ) and the global nav chrome.

RULE 04

Pricing is always DM Sans 500, never Playfair.

Numbers don't get stylized. Prices, stock counts, ratings, durations, year labels, mileage — all DM Sans, font-weight 500, color --near-black. Playfair on a price is an instant reject.

RULE 05

Single mega menu. Six parent categories max.

One mega menu file is the source of truth: mega-menu/mega-menu-final.html. Six parents (Microphones / Outboard / Monitors / Software / Used & Vintage / Studio Services). Don't add a seventh. Don't ship a second variant.

RULE 06

No dark heroes on secondary pages.

Every secondary page starts with a light hero (#EDE8E2). At most one dark accent block per page (#2C2C2A) for a quote or stat — never the first section. Dark editorial heroes (H3) are reserved for HOF and gear-heritage articles only.

Bad"Pro Audio Outfitter · Since 1993" wordmark · 11px eyebrow · Playfair $3,495 price · red CTA on Sell or Trade · dark hero on About page.
Good"Vintage Pro Audio" wordmark · 12px eyebrow · DM Sans 500 $3,495 price · amber CTA on Sell or Trade · light #EDE8E2 hero on About page.

03 / 11

Pick a template.

Every secondary page maps to one of 5 templates. Pick by purpose, not preference. Each template has 2-3 live built examples to copy from. Open the templates buffet to compare side-by-side.

T1 · EDITORIAL LIGHT

Image-led marketing landing.

Use when launching a new program / collection landing that needs to convert visitors quickly and doesn't have long-form content.

Live examplessell-or-trade · tech-shop · studio-installations
T2 · DEEP ARTICLE

Long-form heritage / Hall of Fame.

Use when writing a 2,000–3,000 word story-led page where authority and SEO matter more than fast conversion. Dark editorial hero (H3).

Live exampleshall-of-fame · neumann-u47 · neve-1073-guide
T3 · PROGRAM / SERVICE

3-step process + pricing transparency.

Use when describing a paid program / service / financing offer where the visitor needs to understand how it works and what it costs.

Live examplesfinancing · vk-pro · trade-program · warranty
T4 · PROMO / DROP

Time-bound campaign landing.

Use when you have a time-bound offer or limited inventory drop and the page needs urgency cues + photo-led hero (H4).

Live examplesdemo-deals · open-box · black-friday · ua-promotions
T5 · POLICY / LONG-FORM

Utility, no hero photo.

Use when writing a policy / terms / FAQ / support / contact page where users come with a specific question and need to find the answer fast.

Live examplesshipping-policy · returns · privacy-policy · faq
— DECIDING?

Match by content shape, not topic.

Long story → T2. Process you charge for → T3. Time-bound → T4. Legal / policy → T5. Everything else → T1.

If unsureDefault to T1 Editorial Light. It's the most flexible and matches the section rhythm above.
04 / 11

Pick a header.

4 hero families, bucketed by page type. PLP / category pages pick from H1 or H2. Secondary content pages pick from H2, H3, or H4. Open the headers buffet for inline previews.

Bucket 1 · PLP / category headers

H1 · SPLIT PRODUCT

Default PLP — copy left, hero photo right.

Use on every category landing where you have a strong hero photo. 50/50 split, 280–360px tall.

H2 · CENTERED LIGHT

Secondary PLP — no image needed.

Use on PLPs without a hero photo (Used Gear, Open Box overflow). Quick to ship.

Bucket 2 · Secondary content headers

H2 · CENTERED LIGHT

Daily-driver for every program / service page.

Use on Sell or Trade, Tech Shop, Financing, Studio Installs. Most of T1 and T3 use this.

H3 · FULL DARK EDITORIAL

HOF / heritage / deep article only.

Use on Hall of Fame articles and gear heritage long-form. Near-black bg, white serif headline. Sparingly — at most one per page.

H4 · PHOTO BG OVERLAY

Promo / drop / campaign.

Use on time-bound promo landings (Demo Deals, Open Box drops, holiday). Requires real photo.

— RULE

One header per page. No exceptions.

Don't stack two heroes. Don't follow a hero with a second hero in disguise (giant photo banner). The next section is always a strip, grid, or content block.

05 / 11

Pick a PLP layout.

4 PLP layouts, picked by category type. Default for most. Spotlight for marquee. Editorial for story-led. Filter Demo for deep taxonomies. Open the category buffet.

C1 · DEFAULT

Dark strip + 3-up grid + sticky filters.

Daily driver. Use unless you have a specific reason not to.

C2 · SPOTLIGHT 50/50

Split hero (image right) + grid.

Use on marquee categories (Microphones, Outboard, Monitors) where you have a strong hero product photo.

C3 · EDITORIAL 6-GRID

Mixed grid + dark editorial interruption.

Use on story-led collections (Vintage, Open Box drops, curated edits). Inspired by the Open Box pattern.

C4 · FILTER DEMO

Sticky left filter rail + dense grid.

Use on deep taxonomies where filtering is the primary user action (Vintage Search, full Microphone catalog).

06 / 11

Pick a value strip.

11 strip variants exist — but only 4 are recommended. The rest are alternates or flagged for kill. Open the strip picker to compare side-by-side.

V7 / V10 · CREDENTIAL BAR

Default for landing pages.

4-stat with big Playfair numbers + small amber labels. V7 = off-white, V10 = warm-grey. Pulled from the locked main prototype. Strongest VK pattern by a mile.

V8 · TRUST STRIP w/ ICONS

Daily-driver post-hero.

SVG icon circles + headline + sub-line. Best post-hero placement on PLP and secondary marketing landings.

V11 · DARK PRE-FOOTER

Trust closer above the footer.

Near-black bg, white Playfair titles, grey body. Closes the page with serious trust language right before footer.

V9 · WARM-GREY · RED LABELS

Core ecommerce only.

Same V7 pattern but with red labels. Use when red is the page accent (Open Box, core PLP / PDP).

— FLAGGED FOR KILL

V1 (plain text 4-col).

Currently on most secondary pages. Too quiet, no visual anchor. Replace with V7 or V10 on next pass.

— ALTERNATES (use sparingly)

V2, V3, V4, V5, V6.

Acceptable but lower priority. Don't introduce on new pages unless V7/V8/V10/V11 don't fit the context.

07 / 11

Typography lock.

Two fonts. That's it. Anything else (Roboto, Inter, system-ui) is a reject. The only open question is which font carries product names — currently in test.

The two fonts

  • Playfair Display — display + headings. H1, H2, H3, hero titles, HOF article titles, large stats. 400 / 500 / 600 / 700.
  • DM Sans — body + utility. Body copy, eyebrows, labels, navigation, buttons, all numbers and prices. 300 / 400 / 500 / 600 / 700.

Type scale

  • H1 hero: Playfair 48–56px / 600 / line-height 1.05
  • H2 section: Playfair 32–40px / 600 / line-height 1.1
  • H3 sub-section: Playfair 18–22px / 600
  • Body: DM Sans 13–17px / 400 / line-height 1.6
  • Eyebrow: DM Sans 12px / 700 / 0.18–0.22em letter-spacing / uppercase / amber
  • Pricing: DM Sans 500 / near-black / never Playfair
  • Button: DM Sans 600 / 13px / 0.06em letter-spacing / uppercase

Open question — product names

Editorial Playfair vs Retail DM Sans on product names.

The conversion-vs-character call. Variant A keeps Playfair on product names (current). Variant B switches to DM Sans (more retail / Sweetwater-like). The hybrid recommendation: B on PLP / PDP, A on HOF / heritage.

Open type test → vote

Banned values

  • #fde8e6 — reads pinkish on uncalibrated screens. Use rgba(26,26,24,0.07) for neutral pills.
  • rgba(192,57,43,0.04–0.08) as a standalone background — looks pinkish. Use --off-white.
  • Roboto, Inter, system-ui, anything that isn't Playfair Display or DM Sans.
  • Any font size below 12px in CSS or inline HTML.
09 / 11

SEO / GEO / AI-agent signals.

Every page ships with the same 5 signals. No exceptions — these are how AI agents (ChatGPT, Perplexity, Google SGE) understand and cite VK content.

Per-page checklist

  • Title tag in format [Page Name] — [Benefit Hook] | Vintage King
  • Meta description, 140–160 characters, action-oriented (verb-led)
  • One JSON-LD block (Service, HowTo, FAQPage, Article, JobPosting, or Product)
  • class="speakable" on the hero <p> for Google SGE
  • Canonical URL + Open Graph image (1200×630, branded)

JSON-LD pick by template

  • T1 Editorial Light → Service schema
  • T2 Deep Article → Article + BreadcrumbList
  • T3 Program / Service → Service + HowTo for the 3-step process
  • T4 Promo / Drop → Offer + Product aggregation
  • T5 Policy / Long-form → FAQPage if Q&A; otherwise WebPage

Boilerplate

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "Service", "name": "VK Tech Shop", "provider": { "@type": "Organization", "name": "Vintage King" }, "areaServed": "US", "serviceType": "Pro audio repair and restoration" } </script>

Handoff conventions.

Filename rules, repo boundaries, and what the agency / dev team needs from us before they start.

Filenames

Secondary pageskebab-case · descriptive · no version suffix in production · e.g. tech-shop.html, sell-or-trade.html
PLPs[category]-plp-[layout].html · e.g. microphones-plp-default.html, microphones-plp-spotlight.html
PDPs[brand]-[model].html · e.g. neumann-u47.html, neve-1073.html
HOF / gear heritage[brand]-[model]-guide.html or [brand]-[model].html · e.g. neve-1073-guide.html

Repo boundaries

  • vk-redesign-final (this repo) — guidelines, buffet, decision tools, single source of truth for the system. Read-only for the agency.
  • vk-secondary-pages — all 60+ standalone secondary HTML files + navigator inventory. Where the agency does the secondary-page build.
  • vintage-king-redesign — locked single-file prototype with all 10 core ecommerce screens + mega menu. Do not edit. Pattern source only.

What the team needs from us before build starts

Pre-build deliverables

  • Type-test decision (Variant A / B / Hybrid) — locks product-name font
  • Final value-strip pick (V7 vs V10 as default) — locks landing-page strip
  • Section-buffet pass (Keep / Maybe / Kill marked) — locks the body section library
  • Real photography spec for V4 strip + H4 hero (resolutions, aspect ratios)
  • Section 179 figures for current tax year
11 / 11

Decide — three open calls before agency handoff.

These three decisions block everything else. Each has a dedicated tool. Walk the team through them in this order.

1. Typography — product name font.

Editorial Playfair (current) vs Retail DM Sans (Sweetwater-like) vs Hybrid (B on PLP/PDP, A on HOF). Vote on the type-test page.

Open type test →

2. Value strip — pick the keepers.

11 variants on the picker. AJ recommends V7 or V10 as the landing-page default + V8 for daily-driver post-hero + V11 above footer. Confirm and kill the rest.

Open strip picker →

3. Section buffet — Keep / Maybe / Kill.

Walk every body-section variant once. Mark winners. Round 2 deletes the losers and the new repo ships only the keepers.

Open section buffet →

Then

  1. Lock the 3 decisions above.
  2. Apply the type pick globally across HOF + PLP + PDP.
  3. Migrate the live secondary pages into the new repo, batched by template family (T2 HOF first — biggest set).
  4. Archive everything that didn't make the keep list.
  5. Hand the new repo + this playbook + the inventory spreadsheet to the agency.
