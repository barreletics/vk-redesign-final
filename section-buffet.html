Reference · Component buffet

One component library. Five rooms. No duplicates.

Every section the team can choose from, organized by where it can live. Headers are bucketed by page type. Body sections are bucketed by page type. Strips are cross-cutting (eligible across page types). Each room shows live previews and lets you mark Keep / Maybe / Kill.

Selections persist in your browser. Done deciding? Hand the keepers to the agency via the Build Playbook.

How to use the buffet

  1. Open each room. Click Keep / Maybe / Kill on every section. Selections persist in your browser per-room (no login).
  2. Disagree with a teammate? Have them mark the same rooms. Compare in the next standup.
  3. Once you're locked, the Build Playbook tells the agency which rooms to use per template (T1–T5) and per PLP layout (C1–C4).
  4. Strips are picked separately — see the strip picker for the recommended pairings (V7 / V10 hero / V8 / V12 / V11 closer).
KeepUse this. It's locked. Goes into Section A of the build spec.
MaybeHold for review. Don't kill — but don't ship without team sign-off.
KillDo not ship. Goes into the agency don't-build list.
