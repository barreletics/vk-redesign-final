# vk-redesign-final

The simplified, organized Vintage King redesign demo. Single entry point: `index.html`.

## What this is
A clean, isolated rebuild distilling 60+ prototype pages into:
- 3 secondary-page templates
- 3 category-page header variants
- 1 product page
- 1 mega menu
- 1 section buffet (every body section, mark Keep / Kill / Maybe)
- 10 core ecommerce screens
- All built secondary content pages, organized

## Repo isolation
- Source repos (`vk-secondary-pages`, `vintage-king-redesign`) are **read-only inputs**. Never modified from here.
- All content here is **copied** from source repos into independent files. Originals untouched.

## Open this first
**`index.html`** — the buffet dashboard.

## Folder map
- `index.html` — dashboard (entry point)
- `style-guide.html` — design rules (slim: colors, type, spacing, no-go)
- `page-layouts.html` — every layout pattern in one place
- `section-buffet.html` — every body section, decide Keep / Kill / Maybe
- `headers/` — 3 header variants
- `secondary/` — 3 secondary page templates
- `category/` — canonical category page
- `product/` — canonical product page
- `core/` — 10 core ecommerce screens
- `mega-menu/` — the one mega menu
- `value-strips/` — value strip option gallery
- `content/` — all built secondary marketing pages
