04 · Rules

Do / Don't.

Always

  • Use Vintage Pro Audio as the tagline next to the wordmark
  • Min font size: 12px on every element
  • Amber on every secondary page accent
  • DM Sans for prices, font-weight 500
  • Light hero (#EDE8E2) on every secondary page
  • Form focus border: var(--vk-red) regardless of page accent
  • One mega menu site-wide

Never

  • Use "Pro Audio Outfitter" — that tagline is retired
  • Drop below 12px anywhere
  • Use Playfair on prices or numbers
  • Use red as a secondary-page accent
  • Build a dark hero on a secondary page
  • Use #fde8e6 or rgba(192,57,43,0.04–0.08) as bg
  • Add a second mega menu
  • Use HTML entities like &amp; in visible UI text — write "and"
