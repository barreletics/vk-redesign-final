VK Design System

One page. Top to bottom. The left nav jumps between sections. The right column is the spec. Every component shown below is rendered with the actual VK CSS — what you see is what ships. Live built pages are linked under each component and listed in Pages.

Read order: Rules → Type → Color → Components → Pages. Min font: 12px everywhere. Slogan: Vintage Pro Audio. Mid-page full-bleed photo: B-L2 (in-body band, not the hero). Stacked hero + 2×2: B-P. Sample photos are Unsplash placeholders in the previews only.

01Rules

The locked rules. These do not get debated per page.

  • One mega menu. Single canonical mega menu across the entire site. No legacy second menu. 6 parent categories.
  • Section rhythm. Every page goes nav → hero (light) → strip → body sections → CTA → footer. Max one dark section per page.
  • Light heroes only. All secondary pages start with a light hero (#EDE8E2). Dark heroes reserved for HOF / heritage articles and Vintage / Open Box PLPs.
  • Min font 12px. Nothing below 12px anywhere — CSS or inline.
  • Pricing in DM Sans 500. Never Playfair on numbers or prices. Conversion rule.
  • Slogan: Vintage Pro Audio. Replaces "Pro Audio Outfitter" everywhere.

Banned

  • #fde8e6 — too pinkish on uncalibrated screens. Use rgba(26,26,24,0.07) for neutral pills.
  • rgba(192,57,43,0.04–0.08) as a standalone background — looks pinkish. Use var(--off-white) or rgba(26,26,24,0.04–0.08).
  • HTML entities (&amp; etc.) in visible UI text.
  • Playfair Display on prices or numbers.
  • "Free Shipping" or "0% Financing" as value-strip headlines (already in topbar).
  • References to "showroom" / "visit us" / city offices — VK has no physical retail locations.

Accent color rule (locked) — one color per surface

Every accent-eligible element on a single hero or page uses the same color family. That includes: the eyebrow, the italic accent word in a Playfair headline, the primary CTA button, and any colored accent line.

  • Core ecommerce surfaces (homepage, category, product, cart, checkout, FAQ) → red family or gray
  • Secondary surfaces (all content, service, program, policy, HOF pages) → amber family or gray
  • Never mix red and amber on the same surface — pick one and stay in it
  • Gray (rgba(26,26,24,0.45)) is always allowed as a quiet neutral accent
  • Use the accent on one or two words maximum per headline — never a full sentence

04Spacing

Use the 4-px scale. Section padding for the canonical section types is fixed.

  • Scale: 4 · 8 · 12 · 14 · 18 · 22 · 28 · 32 · 40 · 48 · 56 · 64 · 80 · 96 px
  • Hero padding: 56–80 px top/bottom · 32–40 px sides
  • Body section padding: 36–48 px top/bottom · 28–32 px sides
  • Strip padding: 14–24 px top/bottom · 28 px sides
  • Card padding: 18–22 px
  • Container max-width: 1280 px (PLP grids), 1100 px (text-heavy), 720 px (long-form line-length)
  • Hairline borders: rgba(26,26,24,0.08)
